Code Base

The Code Base class is designed for kids who have little or no experience with computer programming — and that's totally okay.

This is where the journey begins. Whether you're 5 or 16, this class will help you understand how coding works in the simplest and most fun way possible.

You'll learn how to think like a coder by solving puzzles, building stories, creating simple games, and making things move on the screen.

We'll use tools that are made just for beginners with colorful blocks and easy instructions that help you see what your code is doing.

You don't have to be good at math or have any special skills — just be curious and ready to try new things.

Each lesson is clear and friendly with step-by-step guidance so you can learn at your own pace and build confidence with every click.

By the end of the course, you'll be proud of what you've made and excited to keep going.
